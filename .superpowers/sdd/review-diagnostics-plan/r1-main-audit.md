## Independent recomputation

The standalone auditor `r1_raw_audit.py` imports neither the benchmark oracle nor either verifier. It independently decodes the saved float32 tapes, replays latest absolute/edge facets, solves their affine values using exact rational propagation from anchors, verifies consistency, reconstructs the unique source path, and computes component and path residuals from the saved model nodes. The benchmark scorer uses Gaussian elimination, so the audit uses a different solution procedure. On these tree sources a unique anchored path suffices; no production Dijkstra result is trusted.

## Limits and audit artifacts

No false accepted answer was observed. This finite empirical fact is separate from the conditional mathematical guarantee for faithful, consistent affine source evidence. For the branched fixed8 path runs, six and twenty-two zero-error acceptances imply one-sided 95% binomial upper bounds of about **39.30%** and **12.73%** respectively; zero acceptances yield no measured selective risk. Small accepted samples must not be advertised as empirically established zero population risk.

All saved candidates were independently scored, but this audit did not rerun every full model forward; live inference replay covers the preregistered lazy subset. The sources are numeric affine tasks, not free natural language. No signed cancellation bound or answer substitution was introduced.
