# Learned graph/revision/feedback/method experiment

## Typed observations and authority

An event is `(op,i,p,v)`, represented in a float32 `[B,T,4]` tensor. `op`, `i`, `p` are validated integer-valued fields; IDs are per-request canonical labels 0 through9. Values have no hidden scale or normalization. Absolute evidence has op0 (initial) or3 (revision); the evidence constrains `x_i=v`. An edge has op1 (initial) or4 (revision), constraining `x_i=x_p+v`. Query op2 requests title i and normally uses parent i/value0. Continuation op6 consumes a real token with no title write. Op5 is rejected. Absolute evidence on an existing child preserves its edge offset. Batches require aligned query positions. The model accepts any positive number of aligned queries; experiments use three.

The dataset generator and `solve_tree` are explicitly labeled oracles. They create answer labels and training-only intermediate supervision. Model/API modules import neither. Graphs are consistent affine forests with two components, exactly ten nodes, canonical ID permutations, randomized fact order, and one observed absolute value in each component. In inverse tasks the first component's observed value is at its terminal node, and the query asks its upstream root. This tests inverse evidence, unlike forward-only parent definitions. Training uses query depths1/3; the held-out structural shift uses depth5. Both include delayed absolute evidence revision, unaffected component updates, and query/revision/query/continuation/query sequences. Only absolute revisions are in primary training; edge revisions are implemented but not claimed measured.

## Distinct states and clocks

Token time t counts consumed observation tokens. Title refinement k counts learned title updates between token events. Structural depth d is a graph property. They are not interchangeable.

The token core is a one-layer width32/head2/FF64 independent implementation of the pinned source mechanics: causal encoder self-attention with RoPE; global encoder memory; decoder previous-hidden RMS normalization and gated merge; decoder local self-attention retaining W-1 KV entries; global cross-attention; feed-forward residual. Embedding is an event-feature projection instead of vocabulary lookup. Layerwise means one decoder layer in this scoped model. Official large-model numerical/training reproduction is not claimed. The copied token core deliberately excludes sibling data generators and oracles.

Decoder state is `H_t=(s_t,C_t^D)` plus immutable-by-title-refinement encoder KV. Title state is `(z_i,a_i,version_i)`: learned vector, observed constraint features, monotonically increasing direct-write version. Refinement computes a trainable map of the old title state, normalized parent/child adjacency aggregates, and observed anchor features. All arms retain the same dense matrix shapes and six refinements per query. Forward zeros the child-to-parent channel; bidirectional keeps it; wrong permutes adjacency rows and columns by one canonical ID; flat uses complete active-title connectivity. The token core sees the same observations in every arm and can potentially bypass graph paths: graph-direction results do not prove information-theoretic impossibility for the entire architecture.

Title-cache version metadata records the direct observed versions used by each refinement. It is provenance, not a claim that finite neural refinements satisfy all constraints. Direct writes refresh that title. Retain keeps all other learned title vectors. All resets every active title on revision. Local resets the changed title and graph-radius neighbors, determined only from observed adjacency and changed ID. Radius1/2/6 is selected on validation final error, then frozen. Policy input excludes target, affected flag, and oracle dependency annotations.

At a query, `consume_to_query` has consumed its token exactly once. `refine_one` changes z and k only. `candidate` reads node values and requested prediction, without another token update. `commit_feedback` may run once, queues a learned projection of the selected title, and closes the query. For the feedback arm the next decoder gated merge receives `s_t + 0.2 tanh(W_fb z_query)` as previous hidden state. Current output and previously produced probabilities/predictions are immutable. Zero/permutation interventions change only this queued projection after the readout. They never rewrite the current SWA cache or consume an extra token.

## Loss and matched controls

The final-only loss averages three query MSEs. The method arm adds0.3 times all-node MSE at these same three query states, using independently checked TRAIN-only solver traces. All arms use the same train examples, seed-specific batch indices, initial tensor values, optimizer and600 updates. All-node forward predictions are computed in every arm; the auxiliary backward term adds work and supervision in the method arm. This is exact procedural intermediate supervision, not unrestricted thinking-style transfer or learning from textual storage.

Allocation is29475 parameters per arm, but effective computation is not fully matched. A seed17 first-training-batch gradient audit finds27170 nonzero-gradient entries for forward,28322 for bidirectional/wrong/flat/method, and29346 for feedback. Reverse-channel inputs are masked in forward; feedback enables an extra projection; auxiliary loss adds backward work. The audit is observed gradient support for one train batch, not a universal count of all possible active operations. `results/parameter-audit.json` contains full per-parameter details.

The primary depth5 shift is an unseen **query depth**, not a wholly unseen dependency depth for the method arm: its all-node targets also supervise the other component, which can reach depth7 in training. A separately frozen supplemental protocol therefore evaluates512 fresh depth8 examples (nine-node query chain and isolated observed node) across all three seeds and six arms. No training changes or model selection use this supplement. The distinction is binding when claiming structural transfer.

Revision comparisons use the identical trained bidirectional checkpoint, identical initial-query budget6, and identical post-update/continuation budget6. Useful revision requires lower affected FINAL MSE and no more than0.01 absolute unaffected FINAL MSE deterioration relative to retain. Unchanged output drift alone is insufficient. Validation selects radius; held-out data never changes selection.

## Independent inference and incremental halting interface

`learning.api.load_model(checkpoint)` needs only model source and a checkpoint. `events_from_records(records)` maps memory worker string entities to canonical IDs; `predict_records` returns query values and all-node maps. Absolute observations on a child can be expressed as `kind=root,parent=None`, preserving earlier edge constraints. Primary exported checkpoints `bidir-17-step600.pt` and `feedback-17-step600.pt` are representative seed17 artifacts, not test-selected winners.

For actual incremental computation use `runtime=model.new_runtime(events,...)`, then `runtime.consume_to_query()`, repeated `runtime.refine_one()`/`candidate()`, finally `runtime.commit_feedback()` exactly once. Earlier queries can receive the fixed6 budget while only the last query is exposed to a verifier. `final_query_candidates` is a lazy final-query convenience iterator: stopping iteration saves remaining title rounds. An external residual verifier may reject candidate maps; it must never substitute its own answer. Full continuation after acceptance uses the Runtime interface and explicit feedback commit.

## Evidence boundaries

The interrupted v1 GRU diagnostic was identified by root review as insufficiently source-faithful and stopped before the first150-step snapshot. Its protocol, source and initial checkpoint remain in `diagnostic-v1`, and its attempt remains in append-only execution.jsonl. No held-out set was opened. v2 contains the corrected source-style core, new source hashes, and a frozen protocol before all held-out access.

Self-audit then found that v2 omitted activation of unknown nodes mentioned only as edge parents, blocking inverse-title propagation. A three-event regression reproduced the defect. v2 training stopped before held-out generation; all completed/partial checkpoints and source remain in `diagnostic-v2`. v3 activates referenced parents without assigning a value or incrementing observed versions, passes that regression, and uses fresh test seeds92331/92332. This structural correction is separate from any outcome-based tuning. Primary results use v3 only; both failed attempts are preserved.

Independent root review identified that direct invocation of the frozen original runner could overwrite existing outputs on restart. Its historical source remains unchanged. The successor `python -m learning.safe_run` refuses any nonempty result/checkpoint destination before invoking that runner; existing artifacts must remain in place, and a future experiment needs a new reviewed output copy. RED/GREEN guard evidence is preserved.

Finite synthetic tests, small width, three seeds and affine forests do not establish unrestricted natural-language ability, general graph solving, training scalability, measured energy, or general thinking-style transfer. Text extraction and archive/retrieval are separate mechanisms connected by the root integration, not silently assumed perfect here.
