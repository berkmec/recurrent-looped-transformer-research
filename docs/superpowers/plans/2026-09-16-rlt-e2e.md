# RLT End-to-End Research Implementation Plan

> For agentic workers: use subagent-driven-development for scoped implementation and review; dispatching-parallel-agents applies to the independent, disjoint research domains below. Execute continuously under the user's authorization.

**Goal:** Implement, run, audit and report a connected research pipeline for all fourteen agreed packages, preserving negative findings and remaining external-validity limits.

**Architecture:** Three independently testable modules: recurrent core; learned text extraction and versioned memory; learned graph revision and feedback. Root connects them, conducts independent checks and assembles the report. No existing experiment is modified.

**Tech Stack:** Python 3.11, existing PyTorch CPU/CUDA environments, NumPy, SQLite, pytest, Matplotlib. No cloud compute or public writes.

**Spec:** ../../../SPEC.md

## Global Constraints

All Binding constraints in SPEC.md apply verbatim. Each worker reads its own brief and SPEC.md. Formalize numerical contracts before coding. Begin with meaningful tests that would fail if the relevant mechanism is wrong; record RED then GREEN evidence. Do not add tests that merely repeat implementation. Freeze protocols before held-out testing; preserve failed runs. Root alone commits, freezes deliveries and changes common documents.
